# Arquivo original das landing1 e landing2

Esta pasta preserva a implementação anterior sem alterações: `src/RaveraLandings.tsx`, `src/RaveraLandings.css`, entradas HTML, configuração Vite e arquivos iniciais. Na implementação original, as duas versões dividiam o mesmo componente e folha de estilos, e a landing2 importava o logotipo textual da landing3.

As versões organizadas e executáveis estão em `src/alternatives/landing1/` e `src/alternatives/landing2/`; consulte o README da raiz para as rotas. Este arquivo serve como referência para comparar ou recuperar qualquer detalhe do código anterior.
